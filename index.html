Tem-sys

A single-file HTML/CSS template. No build step, no dependencies, no framework to learn — just fork it and start editing.

Most templates ship with a build pipeline you didn't ask for. This one is just HTML and CSS — open the file, read it top to bottom, change what you need.

It's released under the MIT license, so you can use it for personal sites, client work, or your next side project with no attribution required. If you ship something with it, or fix a bug along the way, a pull request is always welcome.

WHAT'S INCLUDED
